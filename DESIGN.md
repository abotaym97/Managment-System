# OMDA design reference

The supplied StarAdmin application screenshot is the visual source of truth. Match its light gray canvas, light navigation rail, white active navigation pill, compact KPI strip, cobalt actions, and white panels with small radii. The directory is the primary panel and renewal notices are the secondary column. Use the existing OMDA data and routes. The surrounding promotional artwork and demo content are outside the application reference. English is the default; Arabic mirrors the layout with logical properties. Use the runtime CSS tokens in subscriptions/static/subscriptions/style.css. Keep Django admin controls and permissions.
